# mq-sakura-anim

给 [SakuraQR](https://github.com/KiriKira/SakuraQR) 导出的方块樱花树（`.glb`）配的一段小动画。樱花花瓣从树冠里飘下来，三个方块小人在树下绕着树干你追我赶。动画会配合背景音乐 muque「いいんじゃない」演出：一头巨大的鲸鱼从高空游下来，绕着树冠游动，三人停下来看，然后鲸鱼游走，三人继续往前蹦蹦跳跳。动画写成一个 ES 模块 `scene.js`，可以放进别人的网页里跑，也可以用在 AR 里。

- `index.html`：演示页，也是自检页
- `walkers.html`：三个小人的模型图（正面、四分之三侧、侧面、背面），`?clip=run|look|hop` 切换动作
- `whale.html`：鲸鱼的模型图

## 接口

```js
import setup from './scene.js';
const { update, dispose } = await setup({ THREE, stage, tree, info, mode, showLength });
// 每帧调用 update(dt, elapsed, showTime)，单位秒；用完调用 dispose()
```

- `stage` 是一个 `THREE.Group`，场景里的东西都加在它下面。
- `tree` 是已经放进 stage 的树，只读，不会去动它。
- `info` 就是 `tree.userData.sakuraqr`。
- `mode` 传 `'3d'` 或 `'ar'`，两种模式下场景完全一样。
- 渲染器、相机、相机控制、灯光、背景、地面都由宿主页面负责。scene.js 不碰 DOM，除了 `./assets/`（相对 scene.js 本身）不访问网络。
- `showTime` 是歌曲当前播放到的位置（比如 `audio.currentTime`），演出跟着它走，所以暂停、拖动进度、循环都能对上。不传时，演出用自己的时钟，每 `showLength` 秒（默认 93.27，正好是这首歌的长度）循环一次。
- three.js 用 0.170.0，宿主页面的 import map 要提供 `three` 和 `three/addons/`。

## 场景

- **不放进树里。** 启动时把树自己的三角形按每格 4×4 的分辨率栅格化成竖直的“柱”，每根柱记下哪几段高度是实心的。花瓣和小人只会移动到这些柱显示为空的地方，所以别的码长出来的树也能直接用。
- **花瓣。** 240 片，两种粉色，用一个 InstancedMesh 画。花瓣从树冠外侧的侧壁和树冠下沿冒出来，而且只选下方有足够落差的位置：侧壁旁至少 3 格，树冠下沿则要能一直落到底座。花瓣从不出现在树冠上方，一边长出来一边就开始往下飘，被风吹着边转边落。只有正中间下面有东西时才会停下，碰到台阶边缘会滑下去，所以不会停在半空。落点大多是底座，少数落在较低的树冠台阶上。停几秒后缩小消失（材质只用不透明的，所以用缩小代替淡出），再从树冠里重新出现。小人跑过时会把地上的花瓣踢起来。
- **小人。** `assets/walker-{blue,red,gold}.glb`，配色照参考像素小人：蓝色兜帽配两条辫子、红色法师帽、带角的金色头盔。每个小人是一个蒙皮网格，带一段 `run` 循环动画：身体前倾，并随摆臂左右扭转；手臂和腿大幅摆动；身体在双脚离地时最高、腿经过身下时最低。每一帧都整体抬高到最低点刚好贴地。蓝色小人的两条辫子是单独的关节：平时下垂，每次身体起伏后慢半拍甩起来，跑动时往后飘。
  - 小人沿一个以树干为圆心的圆跑，半径是树干到最近底座边缘距离的一半。只有遇到低矮的树枝和树根时才会偏离圆形绕过去。转弯时身体向内侧倾斜。
  - 蓝色领跑，红色和金色紧跟在后面，彼此忽近忽远。
  - 模型由 `npm run walkers`（`tools/make-walkers.mjs`）生成。精度是每格 8 个体素，同色的面会合并成大矩形，所以三角形不多。单位是“格”（1 = `info.cell`）。
- 随机数用固定种子，每次打开都一样。只用不透明材质，不加灯也不做后处理。对示例树，场景自身一共 4 次绘制调用，约 5 千个三角形。

## 演出（按歌曲时间）

| 时间 | 演出 |
|---|---|
| 0 – 17 秒 | 三人绕着树干追着跑 |
| 17 – 20 秒 | 鲸鱼从高空俯冲下来，到 20 秒刚好进入绕树冠的圆圈 |
| 约 19.6 – 29 秒 | 三人依次减速、停下，转身看鲸鱼：蓝色举手指着，红色双手合在胸前，金色举起双手欢呼 |
| 约 29 秒 | 看腻了，蓝色先跑起来，另外两个跟上；鲸鱼继续绕圈 |
| 55.5 – 63 秒 | 鲸鱼一边绕圈一边抬头往上游，63 秒时完全消失 |
| 63 秒 – 曲终 | 三人改成蹦蹦跳跳地前进（左右手脚交替），直到歌曲循环 |

- **鲸鱼**（`assets/whale.glb`，`tools/make-whale.mjs` 生成）：每格 2 个体素，约 25 格长，带一段 2.4 秒的 `swim` 循环。动画是上下摆尾，鳍跟着拍，头微微点；脊椎分成几节，节与节之间的顶点按两边关节各占一半来混合，弯起来没有裂缝。
- 鲸鱼绕树干游，圆的半径是底座半宽的 2 倍（约 31 格），一圈 40 秒，方向和小人相反。游动时身体向内侧倾斜，脊椎往圆心方向弯，贴着圆弧走。整头鲸鱼一直在树冠上方。场景里只有鲸鱼可以超出“底座外 3 格”的范围，但不会超出它自己的圆（加上鳍）。
- 俯冲和上升时，头朝下或朝上最多 40°，并且会按俯仰角度额外抬高，尾巴和头不会碰到树冠。最后 1.4 秒在高空缩小消失。

- **鲸鱼到达的位置**按三人停下的地方来定：以树干为中心、从上往下看，在三人顺时针 25° 的方向。这样他们是隔着天空看到鲸鱼，不会被树挡住。三人停在哪里取决于追逐的过程，所以俯冲期间（鲸鱼还在高空、看不见时）会预测他们的落脚点，逐渐把鲸鱼在圆上的位置调过去，等三人停稳后锁定。
- 俯冲和上升对称：一开始陡，最后渐渐放平进入圆圈。头的俯仰按前后各 0.5 秒的平均运动方向计算，并做软限制（约 45°），所以从俯冲转成平游是逐渐完成的，不会一下子拉平。

**自动运镜**（演示页）：三人停下来看鲸鱼时，镜头在 2.5 秒内滑到以树干为中心、三人逆时针 45° 的一侧（从上往下看），从斜上方往下看，并且拉到足够远，能把三人和鲸鱼一起框进画面；看鲸鱼期间，镜头会缓缓跟着绕圈的鲸鱼走；他们重新跑起来后，镜头再滑回原来的位置。如果树冠会挡住其中任何一个人，镜头会逐步升高，直到三人都看得见。拖动视角会取消这一次运镜。带 `?view=` 或 `?test=` 时不运镜。

## 本地运行和自检

```sh
npm install                 # three@0.170.0，演示页的 import map 指向 node_modules
node test/serve.mjs         # 打开 http://127.0.0.1:8000/（带 Range 支持，音乐才能拖动进度和循环；python3 -m http.server 不行）
node test/shots.mjs         # 无头 Chromium 跑自检，截图到 screenshots/
```

演示页参数：

- `?view=ne|nw|se|sw|top|wide|w0|w1|w2|group`：机位。`wide` 拉远看鲸鱼，后几个是对准小人的特写
- `?t=秒`：从歌曲的这个时间开始（先按固定步长快进）
- `?pause=1`：快进后停住
- `?mode=ar`：传给 `setup()` 的 `mode`
- `?nomusic=1`：不放背景音乐，演出用 scene.js 自己的时钟
- `?tree=路径`：换一棵树

`?test=1` 会让动画按固定步长快进 90 秒，每 3 秒检查一次：

- 每个小人的每个顶点（蒙皮之后）和每片花瓣的每个角，用向上的射线数穿过树的次数来判断是否在树里面。这个判断不依赖 scene.js 自己的碰撞柱。
- 有没有东西超出底座 3 格，或者低于 y = 0。
- 小人有没有走出底座，彼此有没有撞上。
- 有没有花瓣飘在附近树冠顶面的上方。
- 每片停住的花瓣（平躺且不动），正中间往下 0.1 格内必须碰到树或底座。
- 演出时间线：鲸鱼只在 17–63 秒出现，而且不超出它自己的圆；看鲸鱼期间，每个人头部到鲸鱼的视线不能穿过树；21.5–28.5 秒三人都停住在看；19.4 秒前和 30–63 秒在跑；64 秒后在跳。鲸鱼的每个顶点（蒙皮之后）也要不在树里、不超出底座 3 格。
- 绘制调用、三角形数和 `update()` 的耗时。
- `dispose()` 之后 stage 里是不是只剩下树。

控制台出现报错或警告、或者访问了本地服务以外的网址，也算失败。`node test/field-debug.mjs` 会用文字打印碰撞柱和环路的长度。

## 背景音乐

演示页循环播放 `audio/bgm.m4a`（AAC，93.3 秒，1.5 MB），右上角的按钮显示正在播放「muque - いいんじゃない」，点击暂停或继续。浏览器不允许没有交互就自动出声，所以自动播放被拒绝时，按钮停在暂停状态，等观众点一下。在歌曲开始之前，演出按 scene.js 自己的时钟走；开始之后跟着歌曲的播放位置走；暂停时故事停在当前位置。音乐文件加载失败时，按钮会隐藏。

## 部署

`.github/workflows/pages.yml` 在推送到 `main` 时构建并发布 GitHub Pages：执行 `npm ci`，把 import map 用到的几个 three.js 文件按原路径复制进站点，然后部署。第一次需要在仓库的 Settings → Pages 里把 Source 设成 “GitHub Actions”。

`tree.glb` 是示例树，只给演示页用，不属于动画资源。
